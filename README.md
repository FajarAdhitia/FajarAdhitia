## 👨‍💻 About Me

I'm a developer who enjoys turning ideas into functional and meaningful digital products.

My experience includes developing:

- 🌐 Web applications and e-commerce platforms
- 📱 Android and mobile applications
- 🤖 IoT-based monitoring systems
- 🎨 UI/UX designs and interactive interfaces
- 🎬 Video and multimedia projects

I enjoy learning new technologies, solving technical problems, and working across different parts of a project — from **design and development to system integration**.

### 🚀 Featured Project

**Real-Time IoT Water Quality Monitoring System**

An IoT-based monitoring system for common carp aquaculture that integrates:

- ESP32 microcontroller
- pH, temperature, and TDS sensors
- Firebase real-time database
- Android application
- Real-time monitoring
- Machine learning-based prediction

This project allowed me to work across **hardware, firmware, backend, mobile development, and machine learning** in one integrated system.
